# Images

Drop your photos here using these exact filenames (referenced from `lib/content.ts`) and they'll appear automatically. Anything missing falls back to a styled placeholder, so the site never looks broken while you're filling this in.

- `hero.jpg` — main hero background (portrait orientation, couple photo)
- `trailer-poster.jpg` — poster shown before the trailer video loads/plays
- `profile.jpg` — the profile-selection avatar
- `episode-1.jpg` … `episode-4.jpg` — Our Story episode thumbnails (16:9)
- `bride.jpg`, `groom.jpg` — Main Cast portraits (3:4)
- `cast-1.jpg` … `cast-4.jpg` — Special Appearances (parents etc., square)
- `gallery-1.jpg` … `gallery-8.jpg` — Memories gallery (2:3 portrait works best)

Add/remove/rename entries in `episodes`, `gallery`, `mainCast`, and `specialAppearances` inside `lib/content.ts` to match whatever photos you actually have.
